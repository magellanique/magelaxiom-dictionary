Magelaxiom

"A voyage to liberty."

A clean, portable, always-on-top Windows dictionary for English words, phrases, synonyms, and antonyms.

Download portable exe View source
01

Offline by design

Magelaxiom embeds its lookup index in the executable. Searches do not call dictionary APIs or translation services.

02

Phrase tolerant

It normalizes spaces, dashes, apostrophes, periods, and slashes, so entries like ex-post, ex post, and expost resolve together.

03

Open data

Definitions, synonym sets, and antonym relations are built from Open English WordNet, with attribution kept separate from the MIT app code.
