# Magelaxiom v0.1.0

Initial public release.

## Included

- Portable Windows executable: `Magelaxiom.exe`
- Always-on-top 640x640 desktop dictionary window
- Instant search while typing
- Open English WordNet definitions, synonyms, and antonyms
- Phrase-tolerant matching for dashes, spaces, punctuation, and variants
- Saved terms list
- Embedded Magelaxiom branding and icon
